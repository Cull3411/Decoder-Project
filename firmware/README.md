# Firmware

Drop the working Receiver/Decoder sketch here, for example:

```
firmware/ReceiverDecoder/ReceiverDecoder.ino
```

Until that file is pasted from the Grok Receiver/Decoder project, this folder is a placeholder.

When you add the sketch, include:

- Board and pin for the IR demodulator
- Whether the receiver output is active-low
- How an ID is printed (Serial, LED blink count, display)
